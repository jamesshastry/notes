# 📝 Smart Notes App

A beautiful, feature-rich notes application with full CRUD (Create, Read, Update, Delete) operations.

## ✨ Features

### 📋 Core CRUD Operations
- **Create**: Add new notes with title and content
- **Read**: View all notes in a beautiful grid layout
- **Update**: Edit existing notes inline
- **Delete**: Remove notes with confirmation

### 🎨 User Experience
- **Modern Design**: Beautiful gradient backgrounds and glass-morphism effects
- **Responsive Layout**: Works perfectly on desktop, tablet, and mobile
- **Smooth Animations**: Fade-in effects and hover animations
- **Dark/Light Theme**: Elegant color schemes

### 🔍 Advanced Features
- **Search**: Real-time search through notes by title and content
- **Filtering**: Filter notes by All, Recent, or Favorites
- **Favorites**: Mark notes as favorites with heart icons
- **Statistics**: View total notes, recent notes, and word count
- **Export/Import**: Backup and restore your notes as JSON files

### ⌨️ Keyboard Shortcuts
- `Ctrl/Cmd + N`: Create new note
- `Ctrl/Cmd + F`: Focus search bar
- `Escape`: Close modal dialogs

### 💾 Data Persistence
- **Local Storage**: All notes are saved locally in your browser
- **Auto-save**: Changes are automatically saved
- **Data Export**: Export all notes as JSON file
- **Data Import**: Import notes from JSON file

## 🚀 Getting Started

### Local Development
1. Clone the repository
2. Install dependencies: `npm install`
3. Start the server: `npm start`
4. Open http://localhost:3000 in your browser

### Deployment
The app is configured for easy deployment on Render:
- Web service deployment
- Automatic builds from Git
- Environment variable support

## 🛠️ Technology Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Backend**: Node.js, Express.js
- **Storage**: Browser Local Storage
- **Deployment**: Render.com ready

## 📱 Usage

1. **Creating Notes**: Click "Create New Note" or use `Ctrl+N`
2. **Editing Notes**: Click the "Edit" button on any note
3. **Deleting Notes**: Click "Delete" and confirm
4. **Searching**: Use the search bar to find specific notes
5. **Favorites**: Click the heart icon to mark notes as favorites
6. **Export**: Click "Export Notes" to download your data
7. **Import**: Click "Import Notes" to restore from a backup
